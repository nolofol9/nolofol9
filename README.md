## 🖼 Как добавить своё фото

1. Загрузи фото в репозиторий  
   Например:

```text
assets/photo.jpg
```

2. Добавь этот код в README:

```html

  <img src="assets/photo.jpg" width="220" style="border-radius:20px;" />
</p>
```
